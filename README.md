# Помощник официанта — Telegram + Mini App

Ресторан: Нижний Новгород, Большая Покровская, 49. VK в эту сборку не входит.

## В этой сборке

- Регистрация сотрудника через `/start` с обязательным вводом ФИО или имени.
- Заявки на доступ и роли: **Администратор**, **Управляющий**, **Официант**, **Стажёр**. Управляющий и администратор имеют равные управленческие права.
- Основные действия прямо в Telegram-чате: поиск по части названия, кнопки похожих позиций, карточка с составом, описанием, дополнительной информацией/аллергенами, ценой и наличием; добавление/возврат из стоп-листа.
- Mini App: каталог, поиск, стоп-лист, смены, история, черновики заказов по столам, управление заявками и сотрудниками для управляющих/администраторов.
- Уведомления одобренным сотрудникам при изменении стоп-листа и начале/окончании смены. Инициатор получает подтверждение в своём интерфейсе.
- Автоматическое закрытие смен по московскому времени: воскресенье–четверг в 22:00, пятница–суббота в 00:00.
- Ежедневный отчёт управляющим и администраторам примерно в 10:00 по Москве: стоп-лист на конец предыдущего дня.
- Каталог из архива «полное меню + бар.zip» и цены из сообщения пользователя. Добавлены алкогольные напитки и варианты объёмов.

## Важные границы

- Черновики заказов — внутренний блокнот официанта. Они не отправляются в кассу или на кухню.
- Некоторые названия/объёмы из голосового ввода могут требовать сверки с оригинальной барной картой (например, `Макитра Брют Блан, 750 мл`).
- Если цена не была указана, она остаётся пустой; сумма заказа не рассчитывается, если у одной из позиций нет подтверждённой цены.
- Для уведомлений каждый сотрудник должен хотя бы один раз открыть чат с ботом и нажать `/start`.
- SQLite подходит для одного небольшого развёртывания. Не запускайте несколько реплик приложения с одной SQLite-базой.

## Развёртывание на Bothost

1. Загрузи содержимое архива в приватный GitHub-репозиторий.
2. На Bothost выбери запуск через Dockerfile из репозитория.
3. Задай переменные окружения:
   - `BOT_TOKEN` — токен от BotFather;
   - `ADMIN_TELEGRAM_IDS` — Telegram ID главного администратора, несколько ID через запятую;
   - `WEBAPP_URL` — HTTPS URL Mini App на Bothost;
   - при необходимости `DATABASE_PATH=/app/data/restaurant.db` и `DATA_DIR=/app/data`.
4. Убедись, что `/app/data` сохраняется при перезапусках/деплоях, если Bothost предоставляет постоянное хранилище.
5. Сделай новый деплой и проверь `GET /api/health`, затем напиши боту `/start`.
6. Если токен публиковался в логах или чате, перевыпусти его через BotFather и используй только новый токен в переменных окружения.

## Основные команды

- `/start` — регистрация или главное меню;
- `/id` — Telegram ID;
- `/help` — помощь;
- `/pending` — заявки (управляющий/администратор);
- `/approve ID waiter|trainee|manager|admin` — назначить роль;
- `/employees` — список сотрудников.

Управление сотрудниками также доступно кнопками в Telegram и Mini App.
